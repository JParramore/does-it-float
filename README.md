# Every Float64

A searchable list of all 2⁶⁴ IEEE 754 double-precision (Float64) values, in order.

Useful when you need to check whether your favourite decimal can be stored exactly as a double.

Hosted [here](https://does-it-float.vercel.app/)

Inspired by [every-uuid](https://github.com/nolenroyalty/every-uuid)
